# CLAUDE.md — проект `exam`

Подготовка к вступительному экзамену в аспирантуру ДНУ им. О. Гончара, специальность
**G7 «Автоматизація, комп'ютерно-інтегровані технології та робототехніка»**,
ОНП «Автоматизація та комп'ютерно-інтегровані технології» (набор 2026).

## Что это за проект

Это не код, а учебные материалы. Основной артефакт — конспект в `notes/`, построенный
строго по официальной программе вступительного испытания (`source/G7_program.pdf`,
расшифровка — `program.md`).

## Формат экзамена (из программы)

- Билет: **3 вопроса** — по одному из каждого раздела программы.
- Длительность — **120 хвилин**, оценка по **200-балльной** шкале (проходной уровень ≥ 100,
  «отлично» — 180–200: требуется связь теории с практикой и собственные примеры).
- Три раздела:
  1. Математичні методи оптимізації
  2. Математичне моделювання систем та процесів
  3. Методи сучасної теорії управління

## Правила работы с конспектом

**Язык.** Смешанный по решению пользователя:
- Определения, формулировки теорем, названия методов, заголовки — **українською**
  (в той же терминологии, что в программе: «допустима множина», «цільова функція»,
  «крайні точки», «спостережність» и т.д.).
- Пояснения, интуиция, «как это работает», комментарии к выводам — **по-русски**.
- Ключевые термины при первом упоминании дублировать: `укр (рус)`.

**Уровень изложения.** Читатель уверенно владеет базой (матанализ, линейная алгебра,
ТАУ, вероятность). Не разжёвывать азы; давать систематизацию, формулы, условия
применимости, границы методов, типичные ошибки на экзамене.

**Структура файла темы** — единообразная:
1. `## Суть питання` — 3–5 строк: о чём тема и что от неё хочет комиссия.
2. `## Основні означення та формули` — строго, с формулами.
3. `## Розгорнутий виклад` — основное содержание.
4. `## Каркас відповіді на іспиті` — план ответа на 5–7 минут, по пунктам.
5. `## Типові уточнюючі запитання` — что могут спросить дополнительно + краткие ответы.

**Формулы** — LaTeX в markdown: `$...$` inline, `$$...$$` блочно. Не использовать
юникод-псевдоформулы для сложных выражений.

**Покрытие.** Каждый абзац официальной программы должен быть покрыт хотя бы одним
разделом конспекта. При добавлении темы — проверять по `program.md`, что ничего не
выпало; список соответствия ведётся в `README.md`.

**Достоверность.** Не выдумывать «фирменные» определения кафедры. Если формулировка в
программе нестандартная (например, «стабільно-ефективні компроміси», «ББС»), давать
общепринятую трактовку и помечать, что терминология авторская.

## Команды

Никакой сборки нет. Всё — markdown. Для просмотра формул использовать любой рендерер
markdown с KaTeX/MathJax.
