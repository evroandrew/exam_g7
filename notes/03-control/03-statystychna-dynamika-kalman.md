# 3.3. Статистична динаміка. Оптимальна фільтрація. Фільтри Калмана–Б'юсі

> Покриває: методи статистичної динаміки лінійних АС; випадкові процеси та їх статистичні
> характеристики; проходження випадкових процесів через лінійну та нелінійну системи;
> визначення оптимальної передаточної функції системи; оптимальна фільтрація векторних
> випадкових процесів; фільтри Калмана–Б'юсі.

## Суть питання

Статистическая динамика изучает системы при **випадкових** воздействиях: вместо переходных
характеристик — статистические характеристики выхода, вместо «точности по отклонению» —
дисперсия ошибки. Кульминация — оптимальная фильтрация (Винер → Калман–Бьюси).

## Випадкові процеси та їх статистичні характеристики

**Випадковий процес** $X(t)$ — семейство случайных величин, зависящее от $t$.
Характеристики:
- **математичне сподівання** $m_x(t)=E[X(t)]$;
- **кореляційна функція** $K_x(t_1,t_2)=E[\mathring X(t_1)\mathring X(t_2)]$, где
  $\mathring X=X-m_x$; **дисперсія** $D_x(t)=K_x(t,t)$;
- **взаємна кореляційна функція** $K_{xy}(t_1,t_2)$.

**Стаціонарний у широкому сенсі:** $m_x=\text{const}$, $K_x(t_1,t_2)=K_x(\tau),\ \tau=t_2-t_1$.
**Ергодичний:** усреднение по времени одной реализации = усреднение по ансамблю (позволяет
оценивать характеристики по одной длинной записи — практически важно).

**Спектральна щільність** (теорема Вінера–Хінчина):
$$S_x(\omega)=\int_{-\infty}^{\infty}K_x(\tau)e^{-j\omega\tau}d\tau,\qquad
K_x(\tau)=\frac1{2\pi}\int_{-\infty}^{\infty}S_x(\omega)e^{j\omega\tau}d\omega$$
$$D_x=K_x(0)=\frac1{2\pi}\int_{-\infty}^{\infty}S_x(\omega)\,d\omega$$
— **дисперсія дорівнює площі під спектральною щільністю** (ключевая формула раздела).

**Білий шум:** $S=S_0=\text{const}$, $K(\tau)=S_0\delta(\tau)$ — физически нереализуем
(бесконечная дисперсия), но удобен как идеализация широкополосной помехи.
**Типові процеси:** экспоненциально-коррелированный ($K=D e^{-\alpha|\tau|}$,
$S=\frac{2D\alpha}{\alpha^2+\omega^2}$ — «цветной шум», формируется из белого апериодическим
звеном), гармонический со случайной фазой, винеровский процесс (интеграл от белого шума).

**Формуючий фільтр:** любой стационарный процесс с дробно-рациональной $S_x(\omega)$ можно
получить пропусканием белого шума через звено $W_ф(s)$ с $|W_ф(j\omega)|^2S_0=S_x(\omega)$
(факторизация спектра). Это позволяет ввести случайное воздействие в модель пространства
состояний как $\dot x=Ax+Bu+Gw$, $w$ — белый шум.

## Проходження випадкових процесів через лінійну систему

Для устойчивой стационарной линейной системы с ПФ $W(j\omega)$ и импульсной характеристикой
$w(t)$ при стационарном входе:
$$m_y=W(0)\,m_x,\qquad
S_y(\omega)=|W(j\omega)|^2\,S_x(\omega),\qquad
S_{xy}(\omega)=W(j\omega)S_x(\omega)$$
$$K_y(\tau)=\int\!\!\int w(t_1)w(t_2)K_x(\tau+t_1-t_2)\,dt_1dt_2,\qquad
D_y=\frac1{2\pi}\int_{-\infty}^{\infty}|W(j\omega)|^2S_x(\omega)\,d\omega$$

Последний интеграл (дисперсия выхода) вычисляется по **табличним інтегралам Джеймса–Ніколса–Філліпса**
$I_n$ — стандартный приём расчёта точности САУ при случайных воздействиях.

Свойства: линейное преобразование **гауссівського** процесса даёт гауссовский процесс
(поэтому нормальность сохраняется по всей линейной системе); система работает как **фільтр**,
подавляя частоты вне полосы пропускания ⇒ узкополосная система «обеляет» меньше и даёт
меньшую дисперсию ошибки, но хуже отслеживает полезный сигнал — базовый компромисс.

**У просторі станів** (уравнение Ляпунова для матрицы ковариаций):
$$\dot x=Ax+Gw,\quad E[ww^T]=Q\delta(t-\tau)\ \Rightarrow\ \dot P=AP+PA^T+GQG^T$$
в установившемся режиме $AP+PA^T+GQG^T=0$ — **матричне рівняння Ляпунова**, откуда дисперсии
всех координат состояния. Это основной вычислительный инструмент статистической динамики
для MIMO-систем.

## Проходження через нелінійну систему

Точных общих методов нет. Практические подходы:
1. **Статистична лінеаризація** (Казаков): нелинейность $f(x)$ заменяется эквивалентным
   линейным звеном по двум статистическим коэффициентам:
   $$f(x)\approx k_0 m_x+k_1\mathring x,\qquad
   k_0=\frac{E[f(x)]}{m_x},\quad k_1=\frac{E[f(x)\mathring x]}{D_x}\ \ \Big(\text{або } k_1=\frac{\sigma_{f}}{\sigma_x}\Big)$$
   Коэффициенты зависят от $m_x,D_x$ ⇒ система уравнений для моментов решается итеративно.
   Применяется для расчёта точности систем с насыщением, зоной нечувствительности, релейными
   элементами.
2. **Метод моментів / рівняння Фоккера–Планка–Колмогорова** для плотности $p(x,t)$ —
   точный, но решаемый аналитически лишь в простейших случаях.
3. **Статистичне моделювання (Монте-Карло)** — универсальный численный метод (см. раздел 2).
4. **Метод еквівалентної передаточної функції по першій гармоніці** (гармоническая
   линеаризация) — для автоколебательных систем при узкополосных процессах.

Важное отличие от линейного случая: **нормальність не зберігається**, появляются
корреляции между гармониками, возможны скачкообразные изменения статистики (срыв слежения).

## Визначення оптимальної передаточної функції системи (задача Вінера)

**Постановка:** вход системы $x(t)=s(t)+n(t)$ — сумма полезного сигнала и помехи (случайные
стационарные процессы с известными $S_s,S_n,S_{sn}$). Требуется найти ПФ $W(s)$, минимизирующую
среднеквадратическую ошибку воспроизведения желаемого преобразования $H(s)$ сигнала:
$$J=E\big[(y(t)-s_{бажане}(t))^2\big]\ \to\ \min_{W}$$

**Рішення (фільтр Вінера)** для физически нереализуемого (двустороннего) случая:
$$W_{опт}(j\omega)=\frac{S_{s}(\omega)}{S_s(\omega)+S_n(\omega)}$$
— «пропускать частоты, где сигнал сильнее помехи, подавлять там, где преобладает помеха».
Для **фізично реалізовного** фильтра используется **факторизація Вінера–Хопфа**:
$S_x=\Psi(s)\Psi(-s)$, где $\Psi$ — минимально-фазовая часть, и берётся только каузальная
часть решения (оператор $\{\cdot\}_+$).

Минимальная достижимая дисперсия ошибки:
$$D_{\min}=\frac1{2\pi}\int_{-\infty}^{\infty}\frac{S_s(\omega)S_n(\omega)}{S_s(\omega)+S_n(\omega)}\,d\omega$$

**Ограничения винеровского подхода:** только стационарные процессы, известные спектры,
скалярный случай, решение в частотной области, неудобное для реализации. Именно эти
ограничения снял Калман.

## Оптимальна фільтрація векторних процесів. Фільтр Калмана–Б'юсі

**Постановка в просторі станів (непрерывный вариант — фильтр Калмана–Бьюси):**
$$\dot x=Ax+Bu+Gw,\qquad y=Cx+v$$
$w$ — белый шум процесса, $E[ww^T]=Q\delta$, $v$ — белый шум измерений, $E[vv^T]=R\delta$,
$Q\succeq0$, $R\succ0$, шумы некоррелированы с $x(0)$.

**Рівняння фільтра:**
$$\boxed{\ \dot{\hat x}=A\hat x+Bu+K\,(y-C\hat x),\qquad K=PC^TR^{-1}\ }$$
$$\dot P=AP+PA^T+GQG^T-PC^TR^{-1}CP,\qquad P(0)=P_0$$
— **матричне диференціальне рівняння Ріккаті** для ковариации ошибки $P=E[ee^T]$,
$e=x-\hat x$. В стационарном режиме $\dot P=0$ — алгебраическое уравнение Риккати (ARE),
$K=\text{const}$.

**Структура:** «модель объекта + коррекция по невязке» — тот же наблюдатель Люенбергера, но
коэффициент $L=K$ **оптимальний за критерієм мінімуму дисперсії помилки** и вычисляется из
интенсивностей шумов.

**Дискретний фільтр Калмана** (рабочая форма для реализации в контроллере) — два этапа:

*Прогноз (екстраполяція):*
$$\hat x_{k}^{-}=A_d\hat x_{k-1}+B_du_{k-1},\qquad P_k^{-}=A_dP_{k-1}A_d^T+Q_d$$
*Корекція (оновлення за вимірюванням):*
$$K_k=P_k^{-}C^T\big(CP_k^{-}C^T+R\big)^{-1}$$
$$\hat x_k=\hat x_k^{-}+K_k\big(y_k-C\hat x_k^{-}\big),\qquad P_k=(I-K_kC)P_k^{-}$$

**Властивості:**
1. Оптимален (минимум $E[\|e\|^2]$) среди **всех** оценок для линейной гауссовской задачи;
   среди линейных — оптимален и без гауссовости.
2. **Рекурентний** — не хранит историю измерений, идеален для реального времени.
3. Работает с **нестаціонарними** системами и нестационарными шумами.
4. Даёт не только оценку, но и **її точність** $P$ — что позволяет строить доверительные
   интервалы и диагностику.
5. Настройка — по $Q$ и $R$: увеличение $R$ (доверие модели) → «медленный», сильно
   сглаживающий фильтр; увеличение $Q$ (доверие измерениям) → «быстрый», шумный.
6. Сходимость и устойчивость гарантируются при выявности $(A,C)$ и стабилизируемости
   $(A,GQ^{1/2})$.

**Дуальність з ЛКР/АКОР:** уравнения фильтра Калмана получаются из уравнений оптимального
регулятора заменой $A\to A^T$, $B\to C^T$, $Q\to GQG^T$, $R\to R$ — задача фильтрации дуальна
задаче оптимального управления. Комбинация «ЛКР + фильтр Калмана» = **LQG-регулятор**.

**Нелінійні узагальнення:** расширенный фильтр Калмана (EKF — линеаризация вдоль оценки,
якобианы), сигма-точечный (UKF — беспроизводное преобразование), ансамблевый (EnKF),
частичный (particle filter) для существенно негауссовых задач.

**Практичне застосування (можна навести як приклад):** комплексирование инерциальных
измерений с GNSS; измерение уровня топлива при колебаниях (работа В.Б. Мазуренко, есть в
списке литературы программы!); оценка момента нагрузки и потокосцепления в приводе;
сглаживание показаний технологических датчиков и обнаружение отказов по невязке.

## Каркас відповіді на іспиті

1. Задачи статистической динамики: точность САУ при случайных воздействиях.
2. Случайные процессы: $m_x$, $K_x(\tau)$, $S_x(\omega)$, Винер–Хинчин, $D_x=$ площадь под
   спектром; стационарность, эргодичность; белый и цветной шум, формирующий фильтр.
3. Прохождение через линейную систему: $S_y=|W|^2S_x$, дисперсия через интеграл, табличные
   интегралы; в пространстве состояний — уравнение Ляпунова для ковариации.
4. Нелинейные системы: статистическая линеаризация (два коэффициента), ФПК, Монте-Карло.
5. Задача Винера: постановка, оптимальная ПФ $S_s/(S_s+S_n)$, факторизация Винера–Хопфа,
   минимальная дисперсия, ограничения метода.
6. Фильтр Калмана–Бьюси: постановка в пространстве состояний, уравнения фильтра и Риккати,
   дискретная форма (прогноз/коррекция), свойства, настройка $Q,R$, дуальность с ЛКР.
7. Нелинейные варианты (EKF/UKF) и практические примеры.

## Типові уточнюючі запитання

**— Чому дисперсія дорівнює площі під спектральною щільністю?** Из обратного преобразования
Винера–Хинчина при $\tau=0$: $K_x(0)=D_x=\frac1{2\pi}\int S_x d\omega$.

**— У чому перевага фільтра Калмана перед фільтром Вінера?** Рекуррентная форма во временной
области (реального времени), работа с векторными, нестационарными системами и произвольными
начальными условиями, выдача точности оценки. Винер требует стационарности и решения в
частотной области.

**— Як налаштовують фільтр Калмана на практиці?** $R$ — по паспортным/измеренным дисперсиям
шума датчиков; $Q$ — как «настроечный» параметр, отражающий неточность модели; проверяют по
**білизні невязки** (innovation whiteness test): если невязка не белая, модель или настройки
неверны.

**— Що станеться, якщо модель об'єкта неточна?** Оценка станет смещённой, а $P$ будет
занижать реальную ошибку («переоцінка впевненості») вплоть до расходимости фильтра; лечится
увеличением $Q$, введением фиктивного шума, адаптивной настройкой, робастными фильтрами.

**— Чому статистична лінеаризація дає два коефіцієнти?** Отдельно для математического ожидания
и для центрированной составляющей: нелинейность по-разному преобразует постоянную и
флуктуационную части сигнала.
