# 3.1. Метод простору станів. Фазові траєкторії

> Покриває: метод простору станів; опис лінійних АСР у нормальній формі; структура моделі
> системи в просторі станів; фазові траєкторії.

## Суть питання

Метод пространства состояний — основа «современной» теории управления (в отличие от
«классической», работающей с передаточными функциями). Главные преимущества, которые нужно
назвать: работа с MIMO-системами, описание внутренней динамики (а не только «вход–выход»),
пригодность для нестационарных и нелинейных систем, прямая применимость численных методов и
оптимизации.

## Основні означення

**Стан системи** $x(t)\in\mathbb R^n$ — минимальный набор переменных, знание которых в момент
$t_0$ вместе с входом $u(t),\ t\ge t_0$ полностью определяет поведение системы при $t>t_0$.
Иными словами, состояние — «память» системы; прошлое влияет на будущее только через него.

**Нормальна форма (форма Коші)** описания линейной системы:
$$\boxed{\ \dot x(t)=A(t)x(t)+B(t)u(t),\qquad y(t)=C(t)x(t)+D(t)u(t)\ }$$
- $x\in\mathbb R^n$ — вектор состояния, $u\in\mathbb R^m$ — вектор управлений,
  $y\in\mathbb R^l$ — вектор выходов;
- $A$ ($n\times n$) — **матриця стану (динаміки)**, определяет собственное движение;
- $B$ ($n\times m$) — **матриця керування (входу)**;
- $C$ ($l\times n$) — **матриця виходу (спостереження)**;
- $D$ ($l\times m$) — **матриця прямого зв'язку** (обычно $D=0$ для физически реализуемых
  инерционных объектов).

Для **стаціонарних (LTI)** систем матрицы постоянны. Дискретный аналог:
$$x_{k+1}=A_dx_k+B_du_k,\qquad y_k=Cx_k+Du_k,$$
$$A_d=e^{Ah},\qquad B_d=\int_0^h e^{A\tau}d\tau\,B=A^{-1}(A_d-I)B\ \ (\text{при } \det A\ne0)$$

## Структура моделі в просторі станів

Структурная схема (её надо уметь нарисовать):
```
        ┌──────────────── A ◄───────────┐
        │                                │
u ──► B ─► (Σ) ─► ∫ ─► x ──► C ─► (Σ) ─► y
                          │              ▲
                          └────► D ──────┘
```
Ядро — **інтегратор** (блок $1/s$ по каждой координате состояния); матрица $A$ замыкает
внутреннюю обратную связь. Число интеграторов = порядок системы $n$.

**Розв'язок рівняння стану** (формула Коши):
$$x(t)=\underbrace{\Phi(t,t_0)x(t_0)}_{\text{вільний рух}}+
\underbrace{\int_{t_0}^{t}\Phi(t,\tau)B(\tau)u(\tau)\,d\tau}_{\text{вимушений рух}}$$
где $\Phi(t,t_0)$ — **перехідна матриця стану (фундаментальна матриця)**; для стационарной
системы $\Phi(t,t_0)=e^{A(t-t_0)}$.

**Матрична експонента:** $e^{At}=\sum_{k=0}^{\infty}\frac{(At)^k}{k!}=\mathcal L^{-1}\{(sI-A)^{-1}\}$;
вычисляется через собственные значения/жорданову форму, ряд Тейлора со скейлингом,
формулу Сильвестра или Кэли–Гамильтона.

**Властивості $\Phi$:** $\Phi(t,t)=I$; $\Phi(t_2,t_0)=\Phi(t_2,t_1)\Phi(t_1,t_0)$;
$\Phi^{-1}(t,t_0)=\Phi(t_0,t)$; $\dot\Phi=A\Phi$.

**Стійкість (LTI):** система асимптотически устойчива ⟺ все собственные значения
$\lambda_i(A)$ имеют отрицательные вещественные части ($\operatorname{Re}\lambda_i<0$).
Для дискретной — $|\lambda_i(A_d)|<1$. Критерий Ляпунова: $\exists P\succ0$:
$A^TP+PA=-Q\prec0$.

**Моди руху:** $e^{\lambda_it}v_i$, где $v_i$ — собственные векторы; вещественные $\lambda$ —
апериодические моды, комплексно-сопряжённые — колебательные с частотой
$\omega=|\operatorname{Im}\lambda|$ и затуханием $\operatorname{Re}\lambda$.

## Канонічні форми

Одна и та же система «вход–выход» имеет бесконечно много представлений в пространстве
состояний: замена $\tilde x=Tx$ ($\det T\ne0$) даёт
$$\tilde A=TAT^{-1},\quad \tilde B=TB,\quad \tilde C=CT^{-1},\quad \tilde D=D$$
— **подібне перетворення**; собственные значения $A$ и передаточная функция инвариантны.

Основные канонические формы для $W(s)=\dfrac{b_{n-1}s^{n-1}+\dots+b_0}{s^n+a_{n-1}s^{n-1}+\dots+a_0}$:

| Форма | Особливість |
|---|---|
| **Керована (керованості)** | $A$ — сопровождающая матрица; $B=(0..0\ 1)^T$; удобна для модального синтеза (размещения полюсов) |
| **Спостережна (спостережності)** | транспонированная структура; удобна для построения наблюдателей |
| **Діагональна (модальна, Жордана)** | $A=\operatorname{diag}(\lambda_i)$; разделяет моды, показывает управляемость/наблюдаемость каждой моды |
| **Каскадна / паралельна** | по разложению ПФ на множители/простые дроби |

**Мінімальна реалізація** — представление наименьшего порядка, воспроизводящее заданную ПФ;
существует ⟺ система полностью управляема и полностью наблюдаема (см. `02-...`).

## Фазовий простір і фазові траєкторії

**Фазовий простір** — пространство состояний $\mathbb R^n$; **фазова траєкторія** — кривая,
описываемая концом вектора $x(t)$; совокупность траекторий при разных начальных условиях —
**фазовий портрет**. Для $n=2$ — **фазова площина** (классический инструмент нелинейной
динамики: координаты $x_1=y$, $x_2=\dot y$).

**Особливі (рівноважні) точки** $\dot x=0$ и их тип для линейной системы 2-го порядка
определяется собственными значениями:

| Власні значення | Тип особливої точки | Стійкість |
|---|---|---|
| $\lambda_{1,2}$ дійсні, одного знака $<0$ | стійкий вузол | асимптотично стійка |
| $\lambda_{1,2}$ дійсні, одного знака $>0$ | нестійкий вузол | нестійка |
| $\lambda_{1,2}$ дійсні, різних знаків | сідло | нестійка (є стійкий многовид) |
| комплексні, $\operatorname{Re}\lambda<0$ | стійкий фокус | асимптотично стійка |
| комплексні, $\operatorname{Re}\lambda>0$ | нестійкий фокус | нестійка |
| чисто уявні | центр | стійка за Ляпуновим (не асимптотично) |

**Властивості фазових траєкторій:** через каждую точку (при выполнении условий
существования и единственности) проходит одна траектория — траектории не пересекаются;
в верхней полуплоскости ($x_2=\dot x_1>0$) движение слева направо; траектории пересекают
ось абсцисс под прямым углом.

**Для нелінійних систем** дополнительно появляются: **граничні цикли** (изолированные
замкнутые траектории — автоколебания; устойчивые/неустойчивые/полуустойчивые),
**сепаратриси**, несколько положений равновесия, **області притягання (басейни)**, а в
$n\ge3$ — **дивні атрактори** (хаос, см. `07-...`). Методы построения: изоклин, припасовывания
(для кусочно-линейных систем с релейными элементами), численное интегрирование.

**Практическое применение фазовой плоскости в автоматизации:** анализ релейных и
позиционных систем, систем с сухим трением и люфтом, оценка автоколебаний, синтез
оптимального по быстродействию управления (линия переключения, теорема об $n$ интервалах),
скользящие режимы (движение вдоль поверхности переключения).

## Переваги та обмеження методу простору станів

**Переваги:**
1. Единая форма для SISO и **MIMO**-систем; никакой «матрицы передаточных функций» не нужно
   для расчёта.
2. Описывается **внутрішня динаміка**, включая моды, не проявляющиеся на выходе
   (некомпенсируемые ПФ сокращения — источник скрытой неустойчивости).
3. Применимость к **нестаціонарним** ($A(t)$) и (после линеаризации либо напрямую) к
   **нелінійним** системам $\dot x=f(x,u,t)$.
4. Естественная численная реализация (интегрирование ОДУ), прямой переход к дискретной модели.
5. Основа современных методов: модальное управление, ЛКР/АКОР, фильтр Калмана, наблюдатели,
   $H_\infty$-синтез, MPC.
6. Прямая связь с моделью объекта: координаты состояния часто имеют физический смысл
   (температура, давление, скорость).

**Обмеження:** требуется знание структуры и порядка объекта; состояние часто не измеряется
целиком (нужен наблюдатель); «инженерная» интерпретация запасов устойчивости менее наглядна,
чем частотные показатели; чувствительность к неточности модели (робастность приходится
обеспечивать отдельно).

## Приклад (готовий для дошки)

Двигун постійного струму, спрощено: $J\ddot\theta+b\dot\theta=k_mi$, $L\dot i+Ri=u-k_e\dot\theta$.
Взяв $x=(\theta,\ \dot\theta,\ i)^T$, получаем
$$A=\begin{pmatrix}0&1&0\\0&-b/J&k_m/J\\0&-k_e/L&-R/L\end{pmatrix},\quad
B=\begin{pmatrix}0\\0\\1/L\end{pmatrix},\quad C=(1\ 0\ 0),\quad D=0$$
Координаты состояния — угол, скорость и ток, все с ясным физическим смыслом; при $L\to0$
(быстрая электрическая мода) система редуцируется до 2-го порядка — пример разделения
движений по темпу.

## Каркас відповіді на іспиті

1. Понятие состояния; почему «современная» теория управления построена на нём.
2. Нормальная форма Коши: уравнения, смысл всех четырёх матриц, размерности; структурная схема
   с интеграторами.
3. Решение уравнения состояния: переходная матрица, матричная экспонента, свойства, свободное
   и вынужденное движение.
4. Устойчивость через $\lambda_i(A)$; моды движения; критерий Ляпунова.
5. Неединственность представления, подобные преобразования, канонические формы, минимальная
   реализация.
6. Фазовое пространство и фазовые траектории; типы особых точек; свойства траекторий;
   нелинейный случай (предельные циклы, сепаратрисы, аттракторы).
7. Преимущества и ограничения метода; переход к дискретному описанию.
8. Пример (двигатель / тепловой объект / из своей практики).

## Типові уточнюючі запитання

**— Чому вибір змінних стану неоднозначний?** Любое невырожденное преобразование $\tilde x=Tx$
даёт эквивалентное описание; физически удобны переменные, имеющие смысл (энергозапасающие
элементы: токи в индуктивностях, напряжения на ёмкостях, скорости масс, температуры).

**— Скільки змінних стану потрібно?** Столько, сколько независимых накопителей энергии
(порядок дифференциального уравнения объекта); формально — минимальный порядок реализации.

**— Що інваріантне при перетворенні подібності?** Собственные значения $A$ (полюсы),
передаточная функция, управляемость/наблюдаемость, характеристический полином.

**— Чому траєкторії на фазовій площині не перетинаються?** Из теоремы существования и
единственности решения задачи Коши: через точку проходит единственная траектория (пересечения
возможны только в особых точках).

**— Як пов'язані фазовий портрет і якість керування?** По фазовому портрету видны характер
переходного процесса (колебательность — фокус, апериодичность — узел), наличие автоколебаний
(предельный цикл), области притяжения — то есть допустимые начальные отклонения.
