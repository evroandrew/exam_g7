# 2.7. Системи масового обслуговування: моделювання та оптимізація

> Покриває: СМО та їх призначення; формування реалізацій випадкових потоків однорідних подій;
> моделювання одноканальних СМО; моделювання багатоканальних СМО; оптимізація СМО за
> допомогою алгоритмів функціонування моделі цієї системи.

## Суть питання

СМО — универсальная модель для систем, где заявки (требования) конкурируют за ограниченный
ресурс обслуживания. Ответ должен содержать: классификацию и обозначение Кендалла, аналитику
для простейших случаев (M/M/1, M/M/n, Эрланг), алгоритм имитации и постановку задачи
оптимизации канальности.

## Призначення та структура СМО

**Система масового обслуговування** — система, предназначенная для обслуживания потока
поступающих заявок. Элементы: **вхідний потік заявок**, **черга (накопичувач)**,
**канали (прилади) обслуговування**, **вихідний потік**, **дисципліна обслуговування**.

Примеры в автоматизации: обработка запросов в АСУ ТП и SCADA; обслуживание прерываний
контроллером; передача кадров в промышленной сети; ремонтная бригада и парк оборудования;
конвейер и накопители; станции обслуживания транспорта.

**Класифікація:**
- **з відмовами (без черги)** — заявка, не заставшая свободного канала, теряется (система
  Эрланга); **з чергою** (неограниченной/ограниченной длины или времени ожидания);
- **одноканальні / багатоканальні**; одно-/многофазные;
- **замкнені** (конечный источник заявок — модель обслуживания $m$ станков) / **розімкнені**;
- по дисциплине: FIFO, LIFO, случайный выбор, с приоритетами (относительными/абсолютными).

**Позначення Кендалла:** $A/B/m/K/N/D$ — распределение интервалов между заявками /
распределение времени обслуживания / число каналов / ёмкость системы / размер источника /
дисциплина. $M$ — показательное (марковское), $D$ — детерминированное, $E_k$ — Эрланга,
$G$ — произвольное. Пример: $M/M/3/5$ — три канала, очередь на 2 места.

**Показники ефективності:** вероятность отказа $P_{відм}$, относительная и абсолютная
пропускная способность $Q=1-P_{відм}$, $A=\lambda Q$; среднее число заявок в очереди $L_q$ и
в системе $L$; среднее время ожидания $W_q$ и пребывания $W$; коэффициент загрузки каналов;
вероятность простоя $p_0$.

**Формула Літтла** (справедлива для любой стационарной СМО, независимо от распределений):
$$L=\lambda_{ефект} W,\qquad L_q=\lambda_{ефект}W_q$$

## Формування реалізацій випадкових потоків однорідних подій

**Потік однорідних подій** — последовательность моментов $t_1<t_2<\dots$ появления однотипных
событий. Свойства: **стаціонарність** (интенсивность не зависит от времени),
**ординарність** (вероятность двух событий в малом интервале — $o(\Delta t)$),
**відсутність післядії** (независимость на непересекающихся интервалах).
Поток, обладающий всеми тремя, — **найпростіший (пуассонівський)**:
$$P_k(\tau)=\frac{(\lambda\tau)^k}{k!}e^{-\lambda\tau},\qquad
\text{інтервали}\ \sim\ f(t)=\lambda e^{-\lambda t},\ \ M[T]=\sigma[T]=1/\lambda$$

**Процедури формування реалізацій на ЦОМ:**
1. **Найпростіший потік:** $t_{i+1}=t_i-\frac1\lambda\ln u_i$, $u_i\sim R[0,1]$.
2. **Потік Ерланга $k$-го порядку** (просеивание простейшего): интервал — сумма $k$
   экспоненциальных: $\tau=-\frac1\lambda\sum_{j=1}^{k}\ln u_j$; коэффициент вариации
   $1/\sqrt k<1$ — более регулярный поток.
3. **Нестаціонарний пуассонівський** ($\lambda(t)$): метод прореживания — генерируем поток с
   $\lambda_{max}$, принимаем событие с вероятностью $\lambda(t)/\lambda_{max}$.
4. **Потік із заданим розподілом інтервалів** (рекуррентный, GI): $\tau=F^{-1}(u)$.
5. **Детермінований потік** $D$: $\tau=const$ (такт конвейера, опрос по расписанию).
6. **Потік із групуванням (пакетний)**: разыгрывается момент прихода пакета и его размер.
7. **Потік відмов обладнання**: интервалы по закону Вейбулла/экспоненциальному.

**Проверка сформированного потока:** гистограмма интервалов и проверка согласия ($\chi^2$,
Колмогорова), оценка интенсивности $\hat\lambda=n/T$, проверка независимости (автокорреляция).

## Одноканальні СМО

### Аналітичні результати (для перевірки імітаційної моделі)

**M/M/1** (простейший поток $\lambda$, показательное обслуживание $\mu$, $\rho=\lambda/\mu<1$):
$$p_0=1-\rho,\quad p_k=(1-\rho)\rho^k,\quad L=\frac{\rho}{1-\rho},\quad
L_q=\frac{\rho^2}{1-\rho},\quad W=\frac{1}{\mu-\lambda},\quad W_q=\frac{\rho}{\mu-\lambda}$$
Ключевой качественный вывод: при $\rho\to1$ очередь и время ожидания растут **гіперболічно**
($\propto1/(1-\rho)$) — поэтому проектная загрузка выбирается 0,6…0,8, а не 0,95.

**M/M/1/K** (ограниченная ёмкость): $p_k=\frac{(1-\rho)\rho^k}{1-\rho^{K+1}}$,
$P_{відм}=p_K$, $\lambda_{ефект}=\lambda(1-p_K)$.

**M/G/1** — формула Полячека–Хінчина:
$$L_q=\frac{\lambda^2\left(\sigma_s^2+1/\mu^2\right)}{2(1-\rho)}=\frac{\rho^2(1+C_s^2)}{2(1-\rho)}$$
где $C_s$ — коэффициент вариации времени обслуживания. Вывод, важный для практики:
**зменшення розкиду часу обслуговування зменшує чергу** (при $C_s=0$, т.е. M/D/1, очередь
вдвое меньше, чем при M/M/1) — обоснование стандартизации операций.

### Алгоритм імітації одноканальної СМО (за подіями)

```
стан: зайнятість каналу, довжина черги, годинник модельного часу T
події: ПРИХІД заявки (час t_a), ЗАВЕРШЕННЯ обслуговування (час t_s)

1. Ініціалізація: T=0; t_a = розіграш інтервалу; t_s = ∞; лічильники=0
2. Поки T < T_кін:
   T = min(t_a, t_s)                       // просування часу до найближчої події
   якщо T == t_a:                          // прихід заявки
        t_a = T + розіграш інтервалу       // планування наступного приходу
        якщо канал вільний: зайняти, t_s = T + розіграш часу обслуговування
        інакше: якщо є місце в черзі → стати в чергу
                інакше → відмова (лічильник відмов++)
   інакше:                                 // завершення обслуговування
        обслуговано++; накопичити час перебування
        якщо черга не порожня: взяти заявку (за дисципліною), t_s = T + розіграш
        інакше: канал вільний, t_s = ∞
   накопичення статистики за площами: ∫L dt, ∫L_q dt, час зайнятості каналу
3. Обробка: L = ∫L dt / T, W = ∫L dt / N_прийнятих (Літтл), P_відм = N_відм/N_прих, …
```

Накопление интегральных характеристик «по площадям» (time-weighted) — обязательный приём:
средняя длина очереди считается как $\frac1T\int_0^T L_q(t)dt$, а не как среднее по событиям.

## Багатоканальні СМО

**M/M/n з відмовами (система Ерланга, M/M/n/n)** — формулы Эрланга:
$$p_k=\frac{\alpha^k/k!}{\sum_{j=0}^{n}\alpha^j/j!},\quad \alpha=\frac\lambda\mu,\qquad
P_{відм}=p_n=B(n,\alpha)=\frac{\alpha^n/n!}{\sum_{j=0}^{n}\alpha^j/j!}$$
$$Q=1-P_{відм},\qquad A=\lambda Q,\qquad \bar n_{зайн}=\alpha(1-P_{відм})$$

**M/M/n з необмеженою чергою** ($\rho=\alpha/n<1$) — формула Эрланга C:
$$p_0=\left[\sum_{k=0}^{n-1}\frac{\alpha^k}{k!}+\frac{\alpha^n}{n!(1-\rho)}\right]^{-1},\qquad
L_q=\frac{\alpha^n\rho}{n!(1-\rho)^2}p_0,\qquad W_q=\frac{L_q}{\lambda}$$

**Замкнена СМО (модель обслуговування $m$ машин)** — формулы Энгсета; применяется для
ремонтных бригад и обслуживания парка оборудования.

**Особливості імітації багатоканальної СМО:** список из $n$ каналов с индивидуальными
временами освобождения; событие «завершение» — минимум по каналам; правила выбора канала
(первый свободный, наименее загруженный); возможны разнотипные каналы (разные $\mu_i$),
приоритеты, отказ и восстановление каналов, перерывы. Именно эти усложнения обычно и делают
аналитику невозможной, а имитацию — единственным средством.

**Многофазные системы и сети СМО:** выход одной СМО — вход следующей. Для сетей Джексона
существует произведение решений (product form), в общем случае — только имитация.

## Оптимізація СМО за допомогою алгоритмів функціонування моделі

**Постановка:** выбрать структуру и параметры системы (число каналов $n$, ёмкость накопителя
$K$, интенсивность обслуживания $\mu$, дисциплину, график работы) по экономическому или
техническому критерию.

**Типовий критерій — сумарні витрати за одиницю часу:**
$$C(n)=c_к\,n+c_{оч}\,L_q(n)+c_{відм}\,\lambda P_{відм}(n)\ \to\ \min_{n\in\mathbb{Z}^+}$$
где $c_к$ — стоимость содержания канала, $c_{оч}$ — стоимость ожидания заявки в единицу
времени, $c_{відм}$ — потери от отказа. Функция $C(n)$ **унімодальна за $n$**: с ростом $n$
затраты на каналы растут линейно, а потери от ожидания/отказов падают ⇒ существует
единственный экономически оптимальный уровень канальности; ищется прямым перебором $n=1,2,\dots$
(целочисленная одномерная задача).

**Альтернативные постановки:**
- $\min n$ при ограничениях $P_{відм}\le P_{доп}$, $W_q\le W_{доп}$ (нормативный подход,
  типичный для проектирования систем связи и АСУ);
- многокритериальная: (затраты, время ожидания, загрузка) → фронт Парето;
- оптимизация дисциплины обслуживания (приоритеты): правило **SPT/кратчайшая операция вперёд**
  минимизирует среднее время пребывания; приоритеты по стоимости простоя — правило $c\mu$.

**Схема оптимізації через імітаційну модель (имитационная оптимизация):**
1. Модель СМО как «чёрный ящик»: вход — вектор параметров $x=(n,K,\mu,\dots)$, выход —
   оценка критерия $\hat C(x)$ по $N$ реализациям (случайная величина!).
2. Метод оптимизации, устойчивый к шуму и не требующий производных: полный перебор по
   дискретной сетке (при малой размерности), прямой поиск (Нелдера–Мида, комплекс-метод),
   метаэвристики (имитация отжига, генетические), методы поверхности отклика (RSM),
   стохастическая аппроксимация (Кифера–Вольфовица).
3. **Загальні випадкові числа** для всех вариантов $x$ — резко снижают дисперсию разности
   $\hat C(x_1)-\hat C(x_2)$ и позволяют корректно сравнивать варианты при малом $N$.
4. Проверка статистической значимости различий (доверительные интервалы, t-критерий),
   ранжирование и отбор (ranking & selection).
5. Анализ чувствительности оптимума к $\lambda,\mu$ и к стоимостным коэффициентам —
   обязательная часть, поскольку исходные данные всегда неточны.

**Пример вывода для ответа:** для системы M/M/n при $\alpha=\lambda/\mu=3$ и требовании
$P_{відм}\le0{,}05$ формула Эрланга даёт $n=6$; экономический критерий при $c_к=1$,
$c_{відм}=20$ может дать $n=5$ — расхождение нормативного и экономического решений и есть
предмет обсуждения с заказчиком.

## Каркас відповіді на іспиті

1. Назначение и структура СМО, классификация, обозначение Кендалла, показатели эффективности,
   формула Литтла.
2. Потоки однородных событий: три свойства, простейший поток, формулы, процедуры формирования
   реализаций (экспоненциальные интервалы, Эрланг, прореживание, GI, D).
3. Одноканальная СМО: аналитика M/M/1 (и вывод про $\rho\to1$), M/M/1/K, Полячек–Хинчин;
   алгоритм имитации по событиям; накопление статистики по площадям.
4. Многоканальная СМО: формулы Эрланга B и C, замкнутая система; особенности имитации
   (разнотипные каналы, приоритеты, отказы), сети СМО.
5. Оптимизация: критерий суммарных затрат, унимодальность по $n$, нормативная постановка,
   схема имитационной оптимизации, общие случайные числа, анализ чувствительности.
6. Практический пример из своей области.

## Типові уточнюючі запитання

**— Чому не проектують систему з завантаженням $\rho=0{,}95$?** Из-за гиперболического роста
очереди $L_q\propto\rho^2/(1-\rho)$: при $\rho=0{,}95$ очередь в 19 раз больше, чем при 0,5,
и система крайне чувствительна к малым колебаниям интенсивности.

**— Що дає формула Літтла?** Связь $L=\lambda W$ без предположений о распределениях —
позволяет проверить корректность имитационной модели и пересчитать один показатель через другой.

**— Навіщо аналітичні формули, якщо є імітація?** Для верификации имитационной модели на
частных случаях (M/M/1, M/M/n), для быстрой оценки при проектировании и для понимания
качественных зависимостей.

**— Як враховуються пріоритети?** Очередь становится структурированной: при относительных
приоритетах текущее обслуживание не прерывается, при абсолютных — прерывается с дообслуживанием
или повторным обслуживанием; аналитика существует лишь для простых случаев, общий случай — имитация.

**— Чому імітаційна оптимізація потребує особливих методів?** Значение критерия — случайная
величина: градиент недоступен, сравнение вариантов требует статистической проверки, поэтому
применяют прямой поиск/метаэвристики с уменьшением дисперсии (общие случайные числа).
