# 1.9. Динамічне програмування. Усереднена оптимізація

> Покриває: метод динамічного програмування для багатокрокових завдань прийняття рішень;
> принцип оптимальності Беллмана; основне функціональне рівняння; обчислювальна схема методу
> ДП; методи усередненої оптимізації, усереднена задача математичного програмування, загальні
> властивості її рішення.

## Суть питання

ДП — метод решения **многошаговых** задач принятия решений: вместо одной задачи с $n$
переменными решается $n$ задач с одной переменной, связанных рекуррентным соотношением.
Плата — «прокляття розмірності» по состоянию. Для аспирантуры по автоматизации важна связка:
ДП → уравнение Беллмана → дискретный ЛКР/АКОР и MPC.

## Багатокрокова задача прийняття рішень

Процесс из $N$ шагов; на шаге $k$: состояние $s_k\in S$, решение (управление) $u_k\in U(s_k)$,
переход $s_{k+1}=\varphi_k(s_k,u_k)$, доход/затраты шага $r_k(s_k,u_k)$.
Критерий **аддитивен** (или мультипликативен):
$$J=\sum_{k=0}^{N-1}r_k(s_k,u_k)+r_N(s_N)\ \to\ \min_{u_0..u_{N-1}}$$

Требования применимости ДП:
1. **Аддитивність (сепарабельність)** критерия по шагам.
2. **Марковість (відсутність післядії):** состояние $s_k$ полностью характеризует систему —
   будущее зависит от прошлого только через текущее состояние.
3. Конечность/дискретизуемость множества состояний и управлений (для численной схемы).

## Принцип оптимальності Беллмана

> **Оптимальна стратегія має ту властивість, що якими б не були початковий стан і початкове
> рішення, наступні рішення повинні складати оптимальну стратегію відносно стану, що виник
> внаслідок першого рішення.**

Иными словами: любой «хвост» оптимальной траектории оптимален для той подзадачи, из состояния
которой он начинается. Это позволяет строить решение рекуррентно с конца.

**Основне функціональне рівняння Беллмана** (обратная рекурсия, минимизация):
$$B_k(s)=\min_{u\in U(s)}\Big\{\,r_k(s,u)+B_{k+1}\big(\varphi_k(s,u)\big)\Big\},\qquad
B_N(s)=r_N(s)$$
где $B_k(s)$ — **функція Беллмана (оптимальні майбутні витрати)** из состояния $s$ на шаге $k$.
Оптимальное управление — **синтез (зворотний зв'язок)**, а не программа:
$u_k^*=\mu_k(s)$ — функция состояния. Это принципиально: ДП сразу даёт закон управления по
состоянию, поэтому оно естественно совместимо с обратной связью.

**Стохастичний варіант** (управляемый марковский процесс):
$$B_k(s)=\min_u\Big\{r_k(s,u)+E_{s'}\big[B_{k+1}(s')\,|\,s,u\big]\Big\}$$
Для бесконечного горизонта с дисконтом $\gamma\in(0,1)$:
$$B(s)=\min_u\{r(s,u)+\gamma E[B(s')]\}$$
— решается **ітерацією за значеннями (value iteration)** или **за стратегіями (policy
iteration)**; оператор Беллмана — сжимающий с коэффициентом $\gamma$ (теорема Банаха ⇒
существование и единственность решения). Отсюда прямой мост к обучению с подкреплением
(Q-learning) и адаптивному динамическому программированию.

## Обчислювальна схема методу ДП

**Зворотний хід (backward, основной):**
1. Дискретизировать пространство состояний $\{s^{(1)}..s^{(M)}\}$ и управлений.
2. Положить $B_N(s)=r_N(s)$ для всех состояний.
3. Для $k=N-1,\dots,0$: для каждого состояния $s$ перебрать все $u\in U(s)$, вычислить
   $r_k(s,u)+B_{k+1}(\varphi(s,u))$ (с интерполяцией $B_{k+1}$ между узлами сетки),
   запомнить минимум $B_k(s)$ и аргминимум $\mu_k(s)$.
4. **Прямий хід:** от заданного $s_0$ разворачиваем траекторию:
   $u_k^*=\mu_k(s_k),\ s_{k+1}=\varphi(s_k,u_k^*)$.

**Складність:** $O(N\cdot M\cdot |U|)$, где $M$ растёт экспоненциально с размерностью
вектора состояния: при $q$ уровнях по каждой из $n$ координат $M=q^n$ — **«прокляття
розмірності» (curse of dimensionality)** Беллмана. Практические меры: агрегация состояний,
аппроксимация функции Беллмана (нейросеть, полиномы) — **наближене ДП (ADP)**, декомпозиция,
переход к MPC с конечным горизонтом.

**Класичні приклади для усної відповіді:** распределение ресурсов между $n$ предприятиями;
задача о рюкзаке; задача замены оборудования; кратчайший путь в сетевом графе (алгоритм
Беллмана–Форда — это и есть ДП); дискретный ЛКР.

## Зв'язок з теорією управління (важливо для 180+)

- **Дискретний ЛКР:** для $x_{k+1}=Ax_k+Bu_k$, $J=\sum(x^TQx+u^TRu)+x_N^TSx_N$ функция
  Беллмана квадратична $B_k(x)=x^TP_kx$, и уравнение Беллмана сводится к
  **різницевому рівнянню Ріккаті**
  $$P_k=Q+A^TP_{k+1}A-A^TP_{k+1}B(R+B^TP_{k+1}B)^{-1}B^TP_{k+1}A$$
  с законом $u_k=-K_kx_k$. Это и есть АКОР — прямое пересечение с разделом 3.
- **Неперервний аналог:** уравнение Гамильтона–Якоби–Беллмана
  $-\partial V/\partial t=\min_u\{r(x,u)+(\partial V/\partial x)^Tf(x,u)\}$; для линейно-
  квадратичной задачи даёт дифференциальное уравнение Риккати.
- **Альтернатива** — принцип максимума Понтрягина: даёт программное управление вдоль
  траектории (необходимые условия), тогда как ДП даёт синтез (закон обратной связи), но
  ценой перебора по всему пространству состояний.
- **MPC (прогнозуюче керування)** — ДП на скользящем конечном горизонте, пересчитываемое
  каждый такт: практический обход проклятия размерности.

## Методи усередненої оптимізації. Усереднена задача МП

**Постановка.** Когда параметры задачи $\omega$ случайны или быстро флуктуируют, вместо
решения при каждом их значении решают **усереднену задачу**:
$$\bar f(x)=E_\omega[f(x,\omega)]\to\min,\qquad x\in \bar X,\quad
\bar X=\{x:\ E_\omega[g_i(x,\omega)]\le0\}$$
Это M-постановка стохастического программирования, рассматриваемая как самостоятельный класс:
критерий и ограничения усредняются по распределению параметров (или по времени — для
периодических/быстроосциллирующих процессов, метод усреднения Крылова–Боголюбова).

**Загальні властивості розв'язку усередненої задачі** (то, что спрашивают):
1. **Успадкування опуклості:** если $f(\cdot,\omega)$ выпукла по $x$ при каждом $\omega$, то
   $\bar f$ выпукла (математическое ожидание — линейный оператор, сохраняющий выпуклость) ⇒
   усреднённая задача выпукла даже при сложной зависимости от $\omega$, локальный минимум
   глобален.
2. **Згладжування:** усреднение сглаживает $f$ (свёртка с плотностью) — $\bar f$ может быть
   гладкой, даже если $f(\cdot,\omega)$ негладка; многоэкстремальность частично «размывается».
   Это идея методов сглаживающей/стохастической аппроксимации глобального поиска.
3. **Нерівність Єнсена:** $\bar f(x)=E[f(x,\omega)]\ge f(x,E[\omega])$ для выпуклой по
   $\omega$ $f$ ⇒ **розв'язок задачі з усередненими параметрами (подстановка средних) не
   збігається з розв'язком усередненої задачі** и даёт оптимистично смещённую оценку. Типичная
   инженерная ошибка — «посчитать по средним значениям параметров»; величина
   $E[f(x,\omega)]-f(x,E[\omega])$ есть **вартість ігнорування невизначеності**.
4. **Стійкість (робастність):** решение усреднённой задачи оптимально «в среднем», но может
   быть плохим для отдельных реализаций; для гарантии применяют минимаксную или
   квантильную постановку.
5. **Збіжність вибіркових апроксимацій:** решение SAA-задачи $\frac1N\sum f(x,\omega_s)$
   сходится к решению усреднённой задачи при $N\to\infty$ (закон больших чисел; скорость
   $O(1/\sqrt N)$ по значению критерия).
6. **Диференціювання під знаком математичного очікування:** при условиях регулярности
   $\nabla\bar f=E[\nabla_xf(x,\omega)]$ — обоснование стохастического градиентного метода
   (несмещённая оценка градиента по одной реализации).

**Численные методы усреднённой задачи:** Монте-Карло/SAA + любой детерминированный метод;
стохастическая аппроксимация (Роббинс–Монро, Кифер–Вольфовиц для безградиентного случая);
квадратурные схемы при малой размерности $\omega$; методы усреднения по времени для
динамических систем с быстрыми колебаниями.

**Приложение к управлению:** усреднённая оптимизация настройки регуляторов по ансамблю
режимов работы объекта (вместо одного «номинального» режима) — практический способ получить
настройку, работоспособную во всём диапазоне нагрузок.

## Каркас відповіді на іспиті

1. Многошаговая задача принятия решений: состояние, управление, переход, аддитивный критерий;
   условия применимости ДП (аддитивность, марковость).
2. Принцип оптимальности Беллмана — точная формулировка.
3. Основное функциональное уравнение (детерминированный и стохастический варианты),
   функция Беллмана, управление как синтез.
4. Вычислительная схема: обратный ход, прямой ход, сложность, проклятие размерности и способы
   борьбы (аппроксимация, агрегация, MPC).
5. Связь с ТАУ: дискретный ЛКР → уравнение Риккати; ГЯБ; сопоставление с принципом максимума.
6. Усреднённая оптимизация: постановка, шесть свойств решения (особенно неравенство Йенсена
   и «нельзя считать по средним»), численные методы.
7. Пример из практики (распределение ресурсов / замена оборудования / настройка регулятора
   по ансамблю режимов).

## Типові уточнюючі запитання

**— У чому саме виграш ДП порівняно з прямим перебором?** Перебор всех траекторий —
$|U|^N$ вариантов; ДП — $N\cdot M\cdot|U|$: за счёт того, что все траектории, приходящие в
одно состояние, далее оптимизируются один раз.

**— Чому ДП дає закон керування, а не програму?** Уравнение Беллмана решается для **всех**
состояний, поэтому результат — функция $\mu_k(s)$, то есть обратная связь; принцип максимума
даёт оптимальную траекторию для одного начального условия.

**— Що таке прокляття розмірності і як з ним боротися?** Экспоненциальный рост числа узлов
сетки состояний с размерностью; борьба — параметрическая аппроксимация функции Беллмана,
агрегация состояний, декомпозиция, скользящий горизонт (MPC), обучение с подкреплением.

**— Чи можна застосувати ДП, якщо критерій мультиплікативний?** Да — логарифмированием
сводится к аддитивному (при положительных сомножителях), либо рекурсия строится напрямую с
умножением.

**— Чому розв'язок усередненої задачі не дорівнює розв'язку задачі з усередненими
параметрами?** Из-за нелинейности $f$ по $\omega$ (неравенство Йенсена): $E[f]\ne f(E[\omega])$.
Разница — цена игнорирования разброса параметров.
