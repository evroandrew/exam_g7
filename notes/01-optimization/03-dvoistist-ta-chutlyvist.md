# 1.3. Двоїстість, теорема рівноваги, параметричний аналіз

> Покриває: загальна постановка задачі МП; подвійні (двоїсті) завдання; критерії
> оптимальності, доказ достатності; теорема рівноваги, її наслідки та застосування;
> геометрична інтерпретація двоїстих змінних; характер залежності оптимальних рішень задачі
> ЛП від параметрів.

## Суть питання

Двойственность — это второй взгляд на ту же задачу: прямая ищет наилучший план, двойственная —
наилучшую оценку ресурсов. Практическая ценность: двойственные переменные = **тіньові ціни**
(маржинальная ценность ресурса), дают критерий оптимальности «на месте» и нижние оценки
в методах ветвей и границ.

## Пара двоїстих задач ЛП

| Пряма (P) | Двоїста (D) |
|---|---|
| $c^Tx\to\min$ | $b^Ty\to\max$ |
| $Ax\ge b$ | $A^Ty\le c$ |
| $x\ge0$ | $y\ge0$ |

Правила соответствия (симметричная пара):
- каждому **обмеженню** прямой задачи ↔ **змінна** двойственной, и наоборот;
- $m$ ограничений ↔ $m$ двойственных переменных;
- ограничение-**рівність** ↔ **вільна** (знаконеопределённая) двойственная переменная;
- ограничение-**нерівність** «в сторону критерия» ↔ **неотрицательная** переменная;
- матрица ограничений транспонируется, $b\leftrightarrow c$;
- двойственная к двойственной = прямая (инволютивность).

## Теореми двоїстості

**1. Слабка двоїстість:** для любых допустимых $x$ (P) и $y$ (D):
$$b^Ty \le c^Tx$$
Доказательство в одну строку: $b^Ty\le (Ax)^Ty = x^T(A^Ty)\le x^Tc$.
Следствия: любое допустимое $y$ даёт **нижню оцінку** оптимума прямой (это и есть
bounding в B&B); если $c^Tx^0=b^Ty^0$ — обе точки оптимальны (**критерій оптимальності**,
достаточное условие — это и есть «доказ достатності» из программы).

**2. Сильна двоїстість:** если одна из задач имеет конечный оптимум, то и вторая имеет, и
$$\min c^Tx = \max b^Ty$$
Если прямая неограничена — двойственная несовместна (и наоборот). Возможен случай, когда обе
несовместны.

**3. Теорема рівноваги (доповнююча нежорсткість, complementary slackness):**
допустимые $x^*,y^*$ оптимальны ⟺
$$y_i^*\,(a_i^Tx^*-b_i)=0\ \ \forall i,\qquad x_j^*\,(c_j-A_j^Ty^*)=0\ \ \forall j$$

Смысл:
- если ограничение выполняется **строго** (ресурс недоиспользован, $a_i^Tx^*>b_i$), то
  его двойственная оценка $y_i^*=0$ — «свободный ресурс ничего не стоит»;
- если $y_i^*>0$, то ограничение **активно** (ресурс исчерпан полностью);
- если переменная $x_j^*>0$ (продукт выпускается), то соответствующее двойственное
  ограничение выполняется как равенство — «рентабельность ровно нулевая».

**Наслідки та застосування теореми рівноваги:**
1. Проверка оптимальности без решения задачи заново.
2. Восстановление решения одной задачи по решению другой (решаем ту, что меньше по размеру).
3. Основа **двоїстого симплекс-методу**: держим $z_j-c_j\le0$ (двойственную допустимость) и
   восстанавливаем прямую допустимость — незаменимо при добавлении отсечений Гомори и
   в методе ветвей и границ (после добавления ограничения решение остаётся двойственно допустимым).
4. Экономическая интерпретация: активные/неактивные ресурсы, «узкие места» производства.

## Геометрична інтерпретація двоїстих змінних

$y_i^*$ = **тіньова ціна (shadow price)** $i$-го ресурса:
$$y_i^* = \frac{\partial f^*}{\partial b_i}$$
— скорость изменения оптимума критерия при малом изменении правой части $b_i$ (пока не
меняется оптимальный базис). Геометрически: $y^*$ — коэффициенты разложения градиента
критерия $c$ по градиентам активных ограничений в оптимальной вершине:
$$c=\sum_{i\in I_{act}} y_i^*\, a_i,\qquad y_i^*\ge0$$
То есть $c$ лежит в конусе, натянутом на нормали активных ограничений (нормальный конус —
условие ККТ для ЛП). Если это не так, найдётся ребро улучшения.

В нелинейном случае двойственные переменные — те же множители Лагранжа/ККТ, и
$y^*=\partial f^*/\partial b$ сохраняется как **теорема про чутливість**.

## Характер залежності оптимальних рішень від параметрів (параметричне ЛП)

Рассматривают три типа возмущений:

**1. Зміна вектора $b$ (правих частин).**
Функция оптимума $f^*(b)$ — **кусково-лінійна, опукла** (для min); её градиент на каждом
куске равен $y^*$. Базис остаётся оптимальным, пока $B^{-1}b\ge0$ — это даёт **інтервал
стійкості (диапазон устойчивости) базиса**. На границе интервала $y^*$ скачком меняется:
шадоу-прайс — «локальная» цена, экстраполяция за интервал ошибочна (типичная ошибка на экзамене).

**2. Зміна вектора $c$ (коефіцієнтів критерію).**
$f^*(c)$ — **кусково-лінійна, увігнута** (для min — вогнутая по $c$). Оптимальная вершина не
меняется, пока сохраняются знаки оценок $z_j-c_j\le0$; это даёт диапазон устойчивости по $c_j$.
При выходе за диапазон — скачкообразный переход в соседнюю вершину (решение $x^*$ разрывно
по параметру, значение $f^*$ непрерывно).

**3. Зміна матриці $A$ / додавання змінних або обмежень.**
Добавление ограничения не улучшает оптимум ($f^*$ не убывает для min); добавление переменной
не ухудшает. Пересчёт удобно вести двойственным симплекс-методом.

**Загальний висновок про характер залежності:** оптимальное значение $f^*$ — непрерывная
кусочно-линейная функция параметра (выпуклая по $b$, вогнутая по $c$), а оптимальный план
$x^*$ — кусочно-постоянная (по базисам) и в точках смены базиса разрывная. Именно поэтому в
задачах управления рекомендуют анализировать не только оптимум, но и **інтервали стійкості**
решения — это и есть анализ чувствительности плана к неточности исходных данных.

## Зв'язок з двоїстістю в НЛП

Лагранжева двоїста функція: $\varphi(\mu,\lambda)=\inf_x L(x,\mu,\lambda)$ — всегда вогнута,
даже если исходная задача невыпукла. Двойственная задача $\max_{\mu\ge0}\varphi$.
Слабая двойственность выполняется всегда, **розрив двоїстості (duality gap)** $=f^*-\varphi^*\ge0$
равен нулю для выпуклых задач при условии Слейтера. Лагранжева релаксация именно поэтому даёт
нижние оценки для дискретных задач.

## Каркас відповіді на іспиті

1. Общая постановка задачи МП, пара «прямая — двойственная», правила построения.
2. Слабая двойственность → критерий оптимальности (достаточное условие) с доказательством в 2 строки.
3. Сильная двойственность, четыре возможных исхода пары задач.
4. Теорема равновесия (доп. нежёсткость): формулировка, смысл, четыре применения.
5. Геометрия/экономика двойственных переменных: тіньові ціни, $y^*=\partial f^*/\partial b$,
   разложение $c$ по нормалям активных ограничений.
6. Параметрический анализ: кусочная линейность $f^*$, интервалы устойчивости базиса,
   разрывность $x^*$.
7. Обобщение на НЛП: множители ККТ = двойственные переменные, duality gap.

## Типові уточнюючі запитання

**— Навіщо взагалі двоїста задача, якщо є пряма?** Меньшая размерность (если $m\ll n$),
нижние оценки для B&B, экономическая интерпретация, двойственный симплекс при
перерешивании после добавления ограничения, декомпозиция больших задач.

**— Чи може розрив двоїстості бути ненульовим у ЛП?** Нет — при конечных оптимумах строгая
двойственность в ЛП выполняется всегда. Ненулевой gap характерен для невыпуклых/дискретных задач.

**— Що буде з $y^*$, якщо ресурс надлишковий?** $y_i^*=0$: увеличение запаса не улучшит критерий.

**— Чому $x^*$ розривно залежить від $c$?** Оптимум — вершина; при повороте вектора $c$ через
критическое направление оптимальная вершина скачком меняется на соседнюю.
