# Конспект до вступного іспиту в аспірантуру ДНУ — G7

Специальность **G7 «Автоматизація, комп'ютерно-інтегровані технології та робототехніка»**,
ОНП «Автоматизація та комп'ютерно-інтегровані технології», набор 2026.
Первоисточник — [`source/G7_program.pdf`](source/G7_program.pdf) (скан, 8 стр.), расшифровка —
[`program.md`](program.md).

## Формат іспиту

| Параметр | Значення |
|---|---|
| Форма | письмовий іспит **за білетами** (екзаменаційні листки зберігаються в особовій справі) |
| Склад білета | **3 питання** — по одному з кожного розділу програми |
| Тривалість | **120 хвилин** |
| Оцінювання | **200-бальна** шкала, окремий протокол на кожного вступника |
| Прохідний рівень | ≥ 100 балів; 151–179 — «правильно і логічно, з власними прикладами»; **180–200 — глибокі знання + зв'язок теорії з практикою** |

Три вопроса, прямо названные в программе (готовые ответы — в [`exam-questions.md`](exam-questions.md)):
1. Класифікація задач математичного програмування. Необхідні і достатні умови оптимальності.
2. Системи і фізичні процеси як об'єкти моделювання та їх інформаційні моделі.
3. Адаптивні системи. Класифікація адаптивних систем.

## Як користуватися конспектом

Каждый файл в `notes/` построен одинаково:
1. `## Суть питання` — что от темы хочет комиссия;
2. `## Основні означення та формули`;
3. развёрнутое изложение;
4. **`## Каркас відповіді на іспиті`** — план ответа по пунктам (главное для повторения);
5. **`## Типові уточнюючі запитання`** — вопросы «на добивание» с краткими ответами.

Язык: определения, формулировки и названия — украинские (как на экзамене), пояснения — русские.

**Стратегия повторения:**
- первый проход — читать полностью, отмечать незнакомое;
- второй — только «Каркас відповіді» + формулы;
- третий — [`cheatsheet.md`](cheatsheet.md) и проговаривание трёх официальных вопросов вслух по таймеру
  (6–8 минут на вопрос);
- к каждой теме подобрать **собственный пример из практики** — это прямое требование
  критерия на 180–200 баллов.

## Що дає бали

- **180–200** требует: обобщение и систематизация, использование общеизвестных доказательств
  в собственной аргументации, **власні приклади**, **зв'язок теорії з практикою**, применение
  теории к практическим задачам, логичное последовательное изложение.
- Практический вывод: к каждому теоретическому положению держать наготове инженерный пример —
  из своей работы (АСУ, приборостроение, встраиваемые системы, обработка данных) или из
  литературы кафедры (`program.md`, раздел «Основна література» — там есть работы Мазуренка по
  фильтру Калмана и монографии по ракетно-космической технике; ссылка на них в ответе уместна).
